================================================================================
  HƯỚNG DẪN CẤP TÊN MIỀN & TREO CLOUD HOSTING MIỄN PHÍ (100% FREE)
  CHO SERVER GIẢI CAPTCHA TIKTOK (CAPTCHA ROUTER SERVICE)
================================================================================

Tài liệu này lưu lại các giải pháp đưa Server Captcha từ Localhost lên mạng Internet 
kèm tên miền (Domain) có chứng chỉ bảo mật HTTPS hoàn toàn miễn phí.
Dành cho trường hợp sau này bạn muốn nhiều máy tính / bạn bè cùng dùng chung 1 Server.

--------------------------------------------------------------------------------
LỰA CHỌN 1: CHẠY TRÊN MÁY BẠN + CẤP TÊN MIỀN HTTPS MIỄN PHÍ (KHUYÊN DÙNG ⭐)
--------------------------------------------------------------------------------
Server vẫn chạy trên máy Mac của bạn, nhưng cấp 1 link Web công khai để máy khác gọi vào.

1. CLOUDFLARE TUNNEL (Tốt nhất - Miễn phí không giới hạn băng thông)
   - Trang chủ: https://www.cloudflare.com/
   - Cài đặt trên Mac (qua Terminal):
       brew install cloudflared
   - Câu lệnh tạo link công khai tức thì:
       cloudflared tunnel --url http://127.0.0.1:8000
   - Kết quả: Cloudflare sẽ trả về một đường link dạng:
       https://random-subdomain.trycloudflare.com
   - Cách dùng: Bạn chỉ cần copy link HTTPS này dán vào cấu hình Extension là xong.

2. NGROK (Đơn giản, phổ biến nhất)
   - Trang chủ: https://ngrok.com/
   - Đăng ký tài khoản miễn phí để lấy AuthToken cố định.
   - Cài đặt: brew install ngrok
   - Câu lệnh chạy:
       ngrok http 8000
   - Kết quả: Nhận link dạng: https://xxxx.ngrok-free.app

--------------------------------------------------------------------------------
LỰA CHỌN 2: ĐƯA HẲN SERVER LÊN ĐÁM MÂY (KHÔNG CẦN BẬT MÁY TÍNH 24/7)
--------------------------------------------------------------------------------
Treo code lên Server miễn phí trên mạng, tắt máy tính đi thì hệ thống giải Captcha vẫn chạy.

1. HUGGING FACE SPACES (Tốt nhất cho Python + OpenCV)
   - Trang chủ: https://huggingface.co/spaces
   - Chi phí: 100% Miễn phí vĩnh viễn (gói CPU Basic, 16GB RAM).
   - Link domain được cấp: https://<username>-<tên-repo>.hf.space
   - Cách làm: 
       + Tạo Space mới -> Chọn SDK: Docker hoặc Blank/Gradio.
       + Upload toàn bộ mã nguồn trong thư mục `captcha-service` lên.
       + Server sẽ chạy liên tục 24/7 và cấp sẵn domain HTTPS.

2. RENDER.COM (Web Service Free)
   - Trang chủ: https://render.com/
   - Chi phí: Miễn phí gói Free Web Service.
   - Link domain được cấp: https://<tên-của-bạn>.onrender.com
   - Lưu ý: Bản Free sẽ tự động sleep nếu sau 15 phút không có request. Khi có request 
     đầu tiên thì mất khoảng 30 giây để khởi động lại.

3. ORACLE CLOUD ALWAYS FREE (Cho hẳn 1 VPS Linux miễn phí trọn đời)
   - Trang chủ: https://www.oracle.com/cloud/free/
   - Chi phí: Miễn phí trọn đời (Always Free Tier).
   - Cấu hình: Cấp 1 máy chủ VPS Ubuntu (4 core ARM, 24GB RAM, 200GB ổ cứng).
   - Cách làm: Cài đặt Python 3 trên VPS, clone code về và chạy `python3 captcha_router_server.py`.
     Sau đó trỏ bất kỳ tên miền miễn phí nào vào IP của máy chủ.

--------------------------------------------------------------------------------
CÁCH ĐỔI TÊN MIỀN TRONG EXTENSION SAU KHI CÓ LINK MỚI:
--------------------------------------------------------------------------------
Khi có tên miền mới (ví dụ: https://my-captcha.trycloudflare.com):
Mở file: `src/content/captcha-detector.js`
Tìm 2 dòng:
   const ROUTER_API = "http://127.0.0.1:8000/captcha/solve";
   const FEEDBACK_API = "http://127.0.0.1:8000/captcha/feedback";

Sửa thành:
   const ROUTER_API = "https://my-captcha.trycloudflare.com/captcha/solve";
   const FEEDBACK_API = "https://my-captcha.trycloudflare.com/captcha/feedback";

(Lưu ý: Luôn để lại đuôi `/captcha/solve` và `/captcha/feedback` ở sau tên miền).
